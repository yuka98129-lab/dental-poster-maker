# ポスター・SNSメーカー

歯科医院の「院内ポスター」と「SNSの投稿文」「動画(リール・TikTok)の台本」を、AI(Claude)といっしょにつくるアプリです。
「医院の投稿」と「自分の発信(新人歯科衛生士・学生に向けた発信)」を切り替えられます。

## できること

- **院内ポスター(A4)**: テーマ・だれに向けて・雰囲気を選ぶと、AIが文章をつくり、5種類のデザイン(ミント・さくら・そら・たいよう・キラキラ)に流し込みます。文字は、押すとその場で直せます。「印刷する」で、A4・1ページで印刷(PDF保存もできます)。
- **SNSの投稿文**: 切り口の違う3案と、ハッシュタグ。文字数が出て、直してから、ボタン1つでコピーできます。
- **動画の台本(TikTok・リール、15〜30秒)**: 最初の一言、場面ごとの「話す言葉」と「画面の文字」、キャプション、ハッシュタグ(2案)。
- **医療広告のチェック(目安)**: 「痛くない」「絶対」「日本一」「完治」「ビフォーアフター」など、誤解を招きやすい表現と、「○」の消し忘れに、印と言い換えのヒントを出します。**AIではなく、決まった言葉の一覧で調べます**(`src/lib/ad-check.ts`)。見つからないことは、問題がないという意味ではありません。最終確認は、医院でしてください。
- **自分の発信**: 新人さん向けのテーマ(現場で役立つ仕事のコツ・つまずきやすいポイント・先輩への相談・患者さんへの声かけ・勉強と就職のヒント)。実際の出来事は、AIが作りません(「ひとこと」に書いたものだけを使います)。口調のメモを、端末に覚えておけます。
- 患者さんの個人情報は、一切扱いません(入力欄にも入れないでください)。

## 公開のしかた(Vercel)

1. このフォルダの中身を、新しい GitHub のリポジトリにアップロードします。
2. Vercel で、そのリポジトリを「Import」します(Framework は Next.js のままで大丈夫です)。
3. 「Settings」→「Environment Variables」に、次の2つを入れます。
   | 名前 | 中身 |
   |---|---|
   | `ANTHROPIC_API_KEY` | Claude API の鍵(`sk-ant-` で始まる文字列)。**チャットやコードには書かない** |
   | `CLINIC_PASSCODE` | 院内で決める合言葉。**半角の英数字がおすすめ**(日本語でも動きます) |
4. 「Deployments」→「Redeploy」。「Ready」になったら完成です。
5. 任意: `ANTHROPIC_MODEL` で、使うAIのモデルを変えられます(初期値は `claude-haiku-4-5`)。

合言葉を変えたいときは、`CLINIC_PASSCODE` を書き換えて、Redeploy します。使っている人は、次に使うときに、入れ直すことになります。

## 守っていること

- 鍵は、サーバー側だけで使います(ブラウザには出ません)。
- 合言葉を知っている人だけが使えます。間違いが続くと、少し待たされます(10分で10回まで)。つくる回数も、1か所から10分で30回までです。
- 画面から送られる選択は、決まった選択肢だけを受け付けます(自由な文字は、長さを制限して、AIには「データ」として渡します。中に指示のような文があっても、従いません)。
- AIの失敗は、サーバーの記録にだけ残し、画面にはやさしい文章を出します。

## 開発

```
npm install
npm run dev     # 動作確認(.env.local に ANTHROPIC_API_KEY と CLINIC_PASSCODE を書く)
npm test        # 自動テスト
npm run lint
```

詳しい作りは `CLAUDE.md` を見てください。

## キャンペーン(料金・期間)のポスター

テーマ「キャンペーン・料金のお知らせ」を選ぶと、メニュー(1〜3つ)・通常の金額・キャンペーンの金額・期間・条件の入力欄が出ます。金額や期間は、入れた数字・文字が、そのままポスターに出ます(AIは、タイトルやひとことの文章だけを作ります)。入れた内容は、その端末に覚えておくので、来月は、直すだけです。ポスターの型は「期間バッジ型」と「カード型」の2つ。色は「紺と水色」ほか。

### 画像で保存・保存したキャンペーン・自分の色

- **画像で保存(PNG)**: ポスターの下のボタン。スマホでは共有画面(写真アプリやLINEに送れる)、パソコンではダウンロード。
- **保存したキャンペーン**: キャンペーンの入力欄の下。名前をつけて、この端末に20件まで保存。ポスターができていれば、文章も、いっしょに保存。「呼び出す」で、内容・デザイン・型・色・文章が、もとに戻る(AIは呼ばない)。
- **自分の色**: ポスターのデザインの「自分の色」で、医院の色を選ぶ。明るい色は、白い文字が読めるように、少し濃くなる。

### テイスト・QRコード・記載もれのチェック

- **デザインのテイスト**: 清潔感・高級感・高級サロン風・可愛い・ナチュラル・ポップ。ワンタップで、色・文字の形・角の丸さ・飾りが決まります。そのあと、色だけ変えることもできます。文字の形は、端末に入っているフォントを使うので、端末で少し見え方が変わります。
- **QRコード**: ポスターの右下に置きます(キャンペーンのポスターも、ふつうのポスターも)。URLは、この端末の中でだけ使います。印刷や画像保存の前に、「読み取りテスト」のお知らせが出ます。
- **記載もれ・誤記のチェック**: 医院名・電話番号・期間・過ぎた日付・金額の入れ間違い・QRのURLなどを、ポスターの下に、「要確認」と「お知らせ」で出します。

## v4 で増えたこと

画面の一番下に「バージョン v5」と出ます。公開したあと、これが出ていれば、新しい版に切り替わっています(出ないときは、GitHub の `src` フォルダが、更新されていません)。

- **ポスターからSNS文章**: できあがったポスターを元に、投稿文(3案)を作ります(「ポスターをもとに、SNSの投稿文もつくる」)。
- **季節・イベントのテンプレート**: 入力欄のひな形(4月の新学期・夏休み・年末など)。押すと、テーマ・ひとこと・メモが入ります。
- **SNSのサイズ**: ポスターの下の「A4 / 正方形 / ストーリーズ」で切り替え。それぞれ、PNGで保存できます(正方形 1080×1080、ストーリーズ 1080×1920。ストーリーズは、上下をあけてあります)。
- **写真と文字サイズ**: 写真を1枚のせられます(端末の中で小さくするだけ。保存も送信もしません。**患者さんが写った写真は使わないでください**)。文字は「小さめ/ふつう/大きめ」。入りきらないときは、自動で少し小さくなります。

## v5 で増えたこと

キャンペーン以外のポスター(定期検診・休診のお知らせなど)にも、「ポスターの型」が3つできました。**ふつう型**(いつもの見た目)・**サイドバー型**(左に縦の帯、ポイントに番号)・**大見出し型**(上に大きな見出しの面)。型を切り替えても、AIは呼び直しません(同じ文章が、並べ替わるだけ)。医院ごとに、色・雰囲気(テイスト)・型を組み合わせれば、見た目を変えられます。

- 更新するファイル: `src` フォルダと `CLAUDE.md`、`README.md`(同じ名前のものを上書き)。SQLは、ありません。
